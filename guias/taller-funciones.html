💡 return corta la función, no solo el for

Un return dentro de un bucle termina la función entera de inmediato, no solo esa vuelta del for — por eso alcanza con un return True apenas se cumple la condición, sin necesitar break ni una variable auxiliar.

¿Sabías que...?




🧱 El primer paso hacia los objetos
Separar el reto final en promedio(), contar_aprobados(), etc. es exactamente la misma idea que vas a usar al escribir tus primeras clases: un método es, ni más ni menos, una función que vive adentro de una clase.


🔁 Funciones que se llaman a sí mismas
factorial() se puede escribir de otra forma, haciendo que la función se llame a sí misma en vez de usar un for — se llama recursión. Todavía no la viste en este curso, pero es una técnica muy usada y la vas a encontrar más adelante.
